# IT Campus Infrastructure Visualization

An interactive 3D visualization platform for exploring IT campus infrastructure, building layouts, floor-level information, interconnected structures, and operational deployment.

## 🌐 Live Demo

Explore the project here: https://kyotocampusfinal.netlify.app/

## 📌 Overview

IT Campus Infrastructure Visualization is a web-based project that represents a corporate IT campus through an interactive 3D environment.

The platform allows users to explore building structures, navigate floor layouts, inspect infrastructure elements, and visualize operational deployment information through a centralized interface.

The project demonstrates how 3D visualization and digital twin concepts can improve the presentation and understanding of complex campus environments.

## ✨ Features

- **Interactive 3D Visualization:** Explore a virtual representation of campus infrastructure.
- **Building Exploration:** Navigate interconnected building structures.
- **Floor-Level Navigation:** Select and inspect individual floor layouts.
- **Infrastructure Visualization:** View building components and their spatial relationships.
- **Operational Deployment:** Explore the deployment information represented in the interface.
- **Interactive Camera Controls:** Reset the view and navigate the 3D environment.
- **Exploded Floor View:** Separate floor levels visually for easier exploration.
- **Search Functionality:** Search for available rooms, infrastructure elements, and operational items.
- **Connectivity Visualization:** Explore connections between buildings and basement levels.
- **Target Selection and Zoom:** Focus on selected elements and return to the default view.
- **Centralized Interface:** Access campus visualization and available operational information from one interface.

## 🏢 Project Scope

The virtual environment represents a corporate IT campus with:

- Multiple interconnected buildings.

## 🖱️ How to Use

1. Open the live demo in a modern web browser.
2. Explore the interactive 3D campus environment.
3. Select individual floors to inspect their information.
4. Use the available camera controls to change the viewing angle.
5. Explore the exploded floor view to understand the building layout.
6. Select available infrastructure elements to view their associated details.
7. Use the search functionality to locate supported elements.
8. Reset the camera or zoom to return to a broader view.
